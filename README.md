# Sis-Facturación-IUPB

PIA de la materia Ingeniería de Software I, donde se pretende desarrollar un aplicativo que gestione pedidos y facturas de proveedores a terceros (concretamente empresas). Los encargados de gestionar el repositorio están divididos en 3 ramas, las cuales son: Frontend, Backend y DB-Management. 

Los roles asignados son los únicos que pueden actualizar, subir, verificar y aprobar los commits.
